# Math Problems Engine

A research scaffold for mathematical skill acquisition, problem decomposition,
and the composition of skills into complete solutions.

## Research scope

The research concerns:

- Atomic mathematical actions, their prerequisites, and their observable results.
- Reusable methods composed from those actions.
- Solution paths that use only declared skills and explicit foundation knowledge.
- Cognitive models that connect learner actions to teachable knowledge components.
- Curriculum sequencing and empirical evaluation of learning and transfer.

Mathematical solution sufficiency, prediction of learner performance, and improved
human learning are separate claims with different evidence requirements. A valid
reference solution is not the only acceptable solution, and successful execution
of a composite task does not by itself demonstrate every constituent skill.

## Contents and use

Start with the [research paper catalogue](docs/research-papers.md). It separates
pedagogical frameworks and human-learning evidence from computational models of
skill acquisition and mathematical composition.

This is a documentation-only scaffold. It contains no engine implementation,
runtime dependencies, executable application, or selected workflow framework.
There is no installation or build step.

The catalogue excludes LLM-based question generation and LLM authoring workflows.
Original PDFs and extracted full texts are not redistributed in this repository.
Use the primary-source links in the catalogue to obtain the papers.
